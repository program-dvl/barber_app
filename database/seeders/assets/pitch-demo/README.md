# Atelier pitch-demo imagery

Sixteen project-bundled JPEGs: fourteen distinct fictional profile portraits
(0–9 staff, 10 owner, 11 manager, 12 receptionist, 13 accountant) and two fictional
location interiors. Generated with the built-in OpenAI image generation tool on
2026-11-07, then converted to optimized JPEG (600px portraits; 1600px interiors).
No downloaded portraits, real client photos, remote hotlinks or runtime image API
calls. All images were visually inspected together before inclusion.

These are generated demonstration people and spaces, not photos of an actual
business or customer endorsements. Keep the demo label and private review consent.
The current product has a business gallery rather than a location-photo field;
both interior images are included there with their location names as captions.
